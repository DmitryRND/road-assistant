# Road Assistant

Интеграция навигации, предупреждений о камерах и GPS телефона с EXEED TXL FL2
на Android 11. Проект независимый, не является официальным продуктом EXEED.

- [Описание и режимы](https://intro.0x0a.ru/)
- [Установка: Windows, macOS и браузер](https://intro.0x0a.ru/install.html)
- [Включение ADB](https://intro.0x0a.ru/guide.html)
- [Состав выпуска и ограничения](https://intro.0x0a.ru/releases.html)
- [Сообщить о проблеме](https://github.com/DmitryRND/road-assistant/issues/new/choose)

## Возможности

- Малый виджет карты или навигации на приборной панели; отдельный виджет на ГУ.
- Полноэкранная карта на приборной панели, карточка манёвра и строка «затем».
  Полный экран и возврат включаются удержанием кнопки режимов на руле.
- Вывод манёвров и предупреждений о камерах на HUD.
- Передача GPS с телефона по Wi-Fi и интеграция Яндекс Музыки.
- Дополнительные функции комфорта доступны в зависимости от автомобиля.

## Установка и обновления

Используйте комплект и инструкции на сайте. Установка выполняется на стоящем
автомобиле. Для первого получения семидневного тестового периода ГУ требуется
интернет. После теста платные интеграции доступны по годовой или бессрочной
лицензии; настройки, Wi-Fi, диагностика и обновления остаются доступными.
Лицензии пока выдаются вручную.

Для браузера используйте Chrome/Edge. Выберите автомобиль в USB-диалоге, затем
«Подключение». Если появится окно USB-отладки на ГУ, нажмите «Разрешить/ОК».
При сохранённом доверии повторного окна может не быть. Если подключение зависает,
сохраните журнал установщика. Подробности — [решение проблем](TROUBLESHOOTING.md).

Полные Windows/macOS-комплекты содержат средства удаления; действующая лицензия
для удаления не нужна. Сохраняйте папку recovery между установками. Подробности
и ограничения восстановления описаны в REMOVAL.md внутри комплекта.
